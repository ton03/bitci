# Changelog

## 0.0.1-alpha.1

- Initial public alpha.
- Local queue, configured argv tasks, resource leases, capped logs, and local MCP.
- macOS managed service and trusted same-repository pull-request staging.

## Version policy

BitCI uses Semantic Versioning. Alpha tags use `v0.0.1-alpha.N`. Alpha
interfaces and storage formats can change without migration support.
